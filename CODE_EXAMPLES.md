Login User (UsersModel)\n```php\npublic function login(string $email, string $password): array|false {\n  // Find user by email\n  $user = $this->findByEmail($email);\n\n  if (!$user) {\n    return false;\n  }\n\n  // Verify password\n  if (!password_verify($password, $user['PASSWORD'])) {\n    return false;\n  }\n\n  return $user;\n}\n```\n\n### 3.
